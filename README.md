# 日報・チェック・生産管理 プロトタイプ

機械部品の加工現場向けに、日報・検査チェックシート・生産管理を1つの画面にまとめるイメージを見せるためのプロトタイプです。

**人名・品番・規格値・受注はすべて架空です。** 入力と「決まり」の修正は、開いた端末の中（ブラウザ）だけに保存されます。

公開ページ: https://tsubasagit.github.io/koutei-nippo-prototype/

## 考え方

すべての画面が、1本の「決まり」でつながっています。

> **係 → 人 → 設備 → 工程 → 品番**（この人が、この設備で、この品番のこの工程をやる）

どの画面でも、上で選ぶと下が絞り込まれます。決まりは管理者が「決まりの修正」画面で直し、直した内容はタブレットの選択肢・QRの自動入力・チェック項目にすぐ反映されます。

## 画面

| 画面 | 内容 |
|---|---|
| 入力（タブレット） | 現品票の「品番×工程」QRを読むと、係・人・設備・工程が入ります。QRがないときは係から順に選びます。図面を見ながら、基準寸法から ±（10倍幅のボタンもあり）で合わせてチェックし、区分（初品・中間・終品）と生産数を入れて、日報とチェックを1回で登録します。NG が出たら、測り直すか係長を呼ぶまで登録できません。途中の入力は下書きとして残ります |
| 確認（管理者） | 係→人→設備→工程→品番で絞り込み。今日の報告、NG の処置、報告がまだの人（出勤の人だけ）、決まりにない人の作業、図面に実測値を重ねた詳細 |
| 生産管理 | 受注の納期・残数・サイクルタイム・段取り・設備の稼働率から、設備ごとの負荷と納期に間に合うかを出します。帯のドラッグと▲▼で順番を入れ替え、同じ工程の別の設備に移せます |
| 決まりの修正（管理者） | 係・人・設備・工程・品番の5列。左の列で選ぶと右の列が絞り込まれます。決まりを足す・外す、主担当（QRで入る人）を変える、品番×工程ごとのチェック項目（基準・許容差・刻み・注意の幅・道具）を直す |
| QRコード（印刷） | 品番×工程ごとのQRです（`?part=品番&proc=工程`） |

QRから直接開く例: https://tsubasagit.github.io/koutei-nippo-prototype/?part=3B51120040&proc=LNC

## しくみ

- `index.html` の1ファイルだけで動きます（ビルド不要）
- QRの表示に [qrcodejs](https://cdnjs.com/libraries/qrcodejs) を CDN から読み込みます
- 保存はブラウザの localStorage です。「決まりの修正」画面のいちばん下のボタンで最初の状態に戻せます
- 「AI」と書いた欄は、決まったルールで文章を作っているイメージです。AI にはつないでいません
