# 日報・チェック・生産管理 プロトタイプ

機械部品の加工現場向けに、日報・検査チェックシート・生産管理を1つの画面にまとめるイメージを見せるためのプロトタイプです。

**人名・品番・規格値・受注はすべて架空です。** 登録した内容は保存されず、画面を閉じると消えます。

公開ページ: https://tsubasagit.github.io/koutei-nippo-prototype/

## 画面

| 画面 | 内容 |
|---|---|
| 従業員の入力画面（タブレット） | 品番のQRを読むと、係・担当・設備・工程が自動で入ります。図面を見ながら、基準寸法から ± で合わせてチェックし、生産数を入れて日報とチェックを1回で登録します |
| 管理者の確認画面 | 今日の報告、NG の処置、報告がまだの人、図面に実測値を重ねた詳細を出します |
| 生産管理（設備と納期） | 受注の納期・残数・サイクルタイム・設備の稼働率から、設備ごとの負荷と納期に間に合うかを出します。係・人・品番で絞り込み、帯のドラッグで順番を入れ替えられます |
| QRコード（印刷） | 品番ごとのQRです。開く先が品番ごとに違います（`?part=品番`） |

品番のQRから直接開く例: https://tsubasagit.github.io/koutei-nippo-prototype/?part=3B51120040

## しくみ

- `index.html` の1ファイルだけで動きます（ビルド不要）
- QRの表示に [qrcodejs](https://cdnjs.com/libraries/qrcodejs) を CDN から読み込みます
- 「AI」と書いた欄は、決まったルールで文章を作っているイメージです。AI にはつないでいません
